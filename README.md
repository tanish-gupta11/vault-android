# Vault for Android

Public beta APK for an offline encrypted photo, video, audio and file vault.

## Download

Download [vault.apk](https://github.com/tanish-gupta11/vault-android/releases/tag/v1.0.0-beta) from the public GitHub Release. Android 8.0 or newer.

## Features

- PIN/password unlock with optional Android biometric unlock
- Encrypted storage for photos, videos, audio and other files
- Albums, filters, multi-select hide/unhide/delete
- Encrypted backup and restore
- Auto-lock and screenshot blocking
- Built-in photo/video/audio viewing

## Important security notes

This is a beta release. Keep independent backups and test with disposable copies first. Forgetting the PIN/password can make vault contents unrecoverable. Removing an original file does not remove copies already uploaded to cloud services.

Test status: 45 desktop encryption checks passed and the APK signature verified with Android signature schemes v2 and v3. Fingerprint hardware was not tested on the Samsung test device.
